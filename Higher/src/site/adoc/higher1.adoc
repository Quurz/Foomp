
= Higher1 (rank‑1 HKT)

`org.quurz.foomp.higher.Higher1<WT, A>` describes higher‑kinded types (HKTs) with exactly
one type parameter. It extends xref:hkt.adoc[Hkt<WT>] and `arity()` always returns `1`.

== Purpose

- For type constructors of the form `F<A>` (e.g., Option<A>, List<A>).
- Together with a xref:witness-type.adoc[WitnessType] it identifies the type family.

== Signature (simplified)

[source,java]
----
public interface Higher1<WT extends WitnessType, A> extends Hkt<WT> {
    @Override default int arity() { return 1; }
}
----

== Example

[source,java]
----
enum OptionWT implements WitnessType {}

final class Option<A> implements Higher1<OptionWT, A> {
    // business logic of the Option structure
}

int r = ((Higher1<OptionWT, String>) new Option<String>()).arity(); // 1
----
