
= Higher2 (rank‑2 HKT)

`org.quurz.foomp.higher.Higher2<WT, A, B>` describes higher‑kinded types (HKTs) with
two type parameters. It extends xref:hkt.adoc[Hkt<WT>] and `arity()` always returns `2`.

== Purpose

- For type constructors of the form `F<A,B>` (e.g., Either<L,R>, Map<K,V> as a placeholder modeling).
- Together with a xref:witness-type.adoc[WitnessType] it identifies the type family.

== Signature (simplified)

[source,java]
----
public interface Higher2<WT extends WitnessType, A, B> extends Hkt<WT> {
    @Override default int arity() { return 2; }
}
----

== Example

[source,java]
----
enum EitherWT implements WitnessType {}

final class Either<L, R> implements Higher2<EitherWT, L, R> {
    // business logic of the Either structure
}

int r = ((Higher2<EitherWT, Integer, String>) new Either<Integer, String>()).arity(); // 2
----
