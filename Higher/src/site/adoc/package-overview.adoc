
= Package overview (org.quurz.foomp.higher)

This package contains marker and rank interfaces for modeling higher‑kinded
types (HKTs) in Java.

== Contents

- xref:witness-type.adoc[WitnessType]: Marker for type families (witness types).
- xref:hkt.adoc[Hkt<WT>]: Base interface of all HKTs of a family.
- xref:higher1.adoc[Higher1] … xref:higher4.adoc[Higher4]: Rank interfaces for 1‑ to 4‑ary type constructors.

== Purpose

These interfaces provide a type‑safe, lightweight approach to HKTs in Java and
form the basis for generic library APIs (e.g., Functor/Monad).
