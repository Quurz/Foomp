
= Foomp Higher – Introduction

The "Higher" module provides type helpers for higher‑kinded types (HKTs). It enables
modeling abstractions in Java that are themselves type‑constructive (e.g., Functor/Monad
as type parameterizations over another type).

This module contains, among other things:

- `Hkt<WT>`: Marker interface for all HKT witnesses of a module.
- `WitnessType`: Marker interface for witness types.
- `Higher1<WT, A>` … `Higher4<WT, A, B, C, D>`: Interfaces for HKTs of ranks 1 to 4.

== Package overview

Package: `org.quurz.foomp.higher`

This module forms the foundation for generic higher‑level type work in other
Foomp modules (e.g., Automata) and provides very little runtime functionality —
the focus is on type safety and JavaDoc documentation.
