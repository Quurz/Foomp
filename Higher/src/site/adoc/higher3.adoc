
= Higher3 (rank‑3 HKT)

`org.quurz.foomp.higher.Higher3<WT, A, B, C>` describes higher‑kinded types (HKTs) with
three type parameters. It extends xref:hkt.adoc[Hkt<WT>] and `arity()` always returns `3`.

== Purpose

- For type constructors of the form `F<A,B,C>`.
- Together with a xref:witness-type.adoc[WitnessType] it identifies the type family.

== Signature (simplified)

[source,java]
----
public interface Higher3<WT extends WitnessType, A, B, C> extends Hkt<WT> {
    @Override default int arity() { return 3; }
}
----

== Example

[source,java]
----
enum TripleWT implements WitnessType {}

final class Triple<A, B, C> implements Higher3<TripleWT, A, B, C> {
    // business logic
}

int r = ((Higher3<TripleWT, Integer, String, Boolean>)
          new Triple<Integer, String, Boolean>()).arity(); // 3
----
