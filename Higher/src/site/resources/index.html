Foomp – Higher‑Kinded Types (HKTs) in Java

This module provides a lightweight encoding of higher‑kinded types (HKTs) in Java, based on a witness type marker and rank‑specific interfaces (Higher1–Higher4).

Overview

Java does not natively support HKTs. Foomp approximates this capability via:

  • WitnessType – a marker that encodes the shape of the type constructor,
  • HigherN<WT, …> – interfaces representing HKT ranks (arity 1..4).

A concrete abstraction provides a dedicated witness type and a static helper (e.g., fix / narrow) to convert from a HigherN shape to the concrete implementation where needed.

Getting started

1) Define a witness type

Create one distinct witness type per encoded type constructor. Witness types are usually empty markers. 

public final class BoxW implements WitnessType { private BoxW() {} }

2) Shape public APIs with HigherN

Express APIs in terms of HigherN<WT, …> so they are independent of a concrete implementation. 

public <WT extends WitnessType, A, B>
Higher2<WT, B, A> swap(Higher2<WT, A, B> value) {
    // implementation depends on the concrete type; this is the HKT-shaped signature
    return value; // placeholder
}

3) Provide a fix/narrow helper on concrete types

Concrete implementations typically offer a static fix (or narrow) method to reify a HigherN value into the concrete type. 

public final class Box<A> implements Higher1<BoxW, A> {
    private final A value;
    private Box(A value) { this.value = value; }

    public static <A> Box<A> of(A value) { return new Box<>(value); }

    @SuppressWarnings("unchecked")
    public static <A> Box<A> fix(Higher1<? extends BoxW, A> hkt) {
        return (Box<A>) hkt;
    }
}

Rank / Arity

The rank (or arity) indicates how many type parameters the encoded constructor carries:

  • Higher1<WT, A> → arity 1
  • Higher2<WT, A, B> → arity 2
  • Higher3<WT, A, B, C> → arity 3
  • Higher4<WT, A, B, C, D> → arity 4

Each HigherN interface overrides arity() accordingly (e.g., rank‑2 returns 2).

Guidelines

  • Define one witness type per encoded type constructor.
  • Keep witness types minimal (empty marker types).
  • Use HigherN<WT, …> in public APIs; provide fix/narrow on concrete types.
  • Document the arity and conversion points (where fixing back is expected).

Glossary

Higher‑kinded type (HKT)
A type that abstracts over type constructors (e.g., F<_>), not just values.
Witness type (WT)
Marker that encodes the type constructor’s shape at the type level.
Rank / Arity
Number of type parameters carried by the HKT (rank‑1, rank‑2, …).
Type constructor
A generic “shape” that becomes a concrete type once type parameters are supplied (e.g., List<_>).
Fix / Narrow
Static helper on a concrete type to turn a HigherN<WT, …> back into the concrete implementation.
