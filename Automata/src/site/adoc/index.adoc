= Foomp Automata – Introduction

The Automata module provides simple finite state machines (FSM). It offers:

- A generic interface `StateMachine<S, IA, OA>` abstracting states (S), inputs (IA), and outputs (OA).
- A thread-safe implementation `FiniteStateMachine<S, IA, OA>` that supports both Moore and Mealy automata.
- Localized error messages via `AutomataMessages`.
